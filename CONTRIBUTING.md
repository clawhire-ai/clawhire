# Contributing

Thanks for helping improve the ClawHire Community Pack.

You can contribute corrections, clearer instructions, safer boundaries, better examples and lightweight workflows. The hosted platform's private source code is not part of this repository and is not open for external code contributions.

Before opening a pull request:

1. Remove all personal, customer and confidential information.
2. Keep prompts provider-neutral where practical.
3. State assumptions and limitations explicitly.
4. Do not claim that a workflow performs external actions it cannot perform.
5. Keep each change focused and explain how you tested it manually.

For product ideas and use cases, prefer Discussions. For reproducible problems in public files, use Issues. Security vulnerabilities should follow `SECURITY.md` and must not be posted publicly.
