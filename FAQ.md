# Frequently asked questions

## Is ClawHire open source?

Not as a complete product. ClawHire is a commercial hosted service. Its orchestration, project state, model routing and commercial systems remain private. This repository opens a limited Community Pack of templates, workflows, examples and documentation.

## What is the difference between this repository and ClawHire?

The Community Pack requires you to select agents, run prompts and combine results manually. Hosted ClawHire adds dynamic discovery, persistent project state, coordinated role execution, approvals and revisions.

## Can I register now?

Open registration is unavailable. Apply on the website; applications are manually reviewed and approved applicants receive a one-time invite code.

## Does ClawHire access email, spreadsheets or social accounts?

The current MVP primarily provides planning and text/Markdown deliverables. External-system execution remains in development and should only occur with explicit user authorization and controlled permissions.

## Can ClawHire launch a complete product automatically?

The current version can help clarify requirements and produce research, positioning, MVP planning and related text deliverables. Code execution, deployment and broader product delivery remain in development.

## Is project data made public?

No. A public example must use fictional data or be explicitly authorized and sanitized. Never post sensitive data in a public Issue or Discussion.
