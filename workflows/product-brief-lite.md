# Product Brief Lite / 产品项目 Brief Lite

Use this workflow to turn an early product idea into a testable MVP plan. It is a manual sequence: you provide the brief, run the suggested Community Agents and combine the results yourself.

## 1. Complete the brief

```markdown
# Product Project Brief

## One-sentence idea
## First target user
## Specific problem
## Desired result in two weeks or one month
## Constraints
- Time:
- Budget:
- Technical:
- Compliance:
## Existing assets
## Decision this work should support
```

## 2. Run the roles

1. Use the [Market Researcher](../community-agents/market-researcher.md) to challenge demand and differentiation.
2. Use the [User Researcher](../community-agents/user-researcher.md) to design evidence collection.
3. Give both results to the [Product Strategist](../community-agents/product-strategist.md).
4. Send the combined draft to the [Risk Reviewer](../community-agents/risk-reviewer.md).

When passing work between roles, include the original brief and label what is evidence versus assumption.

## 3. Assemble the validation pack

```markdown
# Product Validation Pack

1. Target user and priority problem
2. Existing evidence and critical assumptions
3. Competitors and alternatives
4. Value proposition
5. MVP scope and explicit non-goals
6. Two-week validation plan
7. Success, revise and stop signals
8. Major risks and open decisions
```

## Hosted-product difference

This Lite workflow requires manual prompting, handoffs and synthesis. Hosted ClawHire dynamically asks follow-up questions, forms project consensus, assigns roles, preserves state, coordinates review and supports revisions.
