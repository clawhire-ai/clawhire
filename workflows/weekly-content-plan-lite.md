# Weekly Content Plan Lite / 一周内容运营计划 Lite

Use this workflow to create a realistic one-week plan for a personal account or small brand. It does not record, edit, log in or publish content.

## 1. Complete the brief

```markdown
# Content Brief

## Platform
## Account goal
## Target audience
## Credible expertise, cases or assets
## Product/service and desired CTA
## Prohibited topics or claims
## Weekly time, people, budget and publishing capacity
## Prior performance data (optional)
```

## 2. Build the plan

1. Give the brief to the [Content Planner](../community-agents/content-planner.md).
2. Ask for 3–5 content pillars and 10 candidate topics before scheduling.
3. Select topics that match both audience value and available evidence.
4. Send claims, customer references and sensitive topics to the [Risk Reviewer](../community-agents/risk-reviewer.md).
