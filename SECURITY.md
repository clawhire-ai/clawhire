# Security policy

Do not disclose vulnerabilities, credentials, customer data or confidential project information in a public Issue or Discussion.

For a suspected vulnerability in the hosted ClawHire product, email [service@clawhireai.com](mailto:service@clawhireai.com) with the subject `Security report`. Include a concise description, affected area, reproduction steps and impact. Please allow us to confirm receipt before making any public disclosure.

The Community Pack consists of text templates and examples. Review all generated output before using it in decisions or external systems, and never paste secrets or unnecessary personal data into an AI tool.
